# 产品界面验证记录

2026-10-23，在本机 Windows 桌面运行 `dist/DesktopTodo.exe`，使用隔离数据目录
`.tools/app-ui-audit`，通过 Computer Use 真实鼠标和键盘操作。

已观察并验证：

- 普通窗口显示便签标题、任务列表、筛选菜单和原生任务输入框。
- 聚焦底部输入框，输入“完成初始需求验收 🎯”，按 Enter 后任务出现。
  读取程序快照，确认中文和补充平面 Unicode 字符完整保留。
- 点击任务状态圆点，绿色完成标记和删除线出现；程序快照中状态变为 2。
- 打开筛选菜单，用方向键选择“未完成”并按 Enter，已完成任务被筛除，
  界面出现“这个分类里暂无待办”。
- 之前实际鼠标拖动任务把手的检查已确认列表顺序改变；自动化集成测试另行
  覆盖筛选排序时隐藏任务位置不变。

本记录不把原生窗口样式标志作为所有桌面交互的充分证明。
另用独立 Python 原生窗口覆盖产品便签的相同矩形，实测三种层级：

- 桌面便签解锁后仍被非全屏普通窗口遮挡，中心命中属于 Python 进程。
- 切到置顶模式，激活 Python 普通窗口，截图显示便签仍覆盖其内容，中心命中属于产品。
- 切到普通窗口模式，重新激活 Python 窗口，便签被覆盖，中心命中重新属于 Python。

事实记录见 [实际层级检查](product-window-layer-results.json)。这些检查使用正式产品，
不使用 SDK 探针代替。随后已恢复桌面锁定模式，供最后的人工交互检查。

窗口销毁并重建后的数据、模式和解锁控件恢复已通过程序级集成测试，
但真实 Explorer 进程重启、“显示桌面”、多屏切换仍需继续验收。
