# 初始需求验收

2026-10-23。以产品 `app/` 和 `dist/DesktopTodo.exe` 为准；SDK 原型结果不代替产品验收。

| 原始要求 | 当前实现 | 验证与结论 |
| --- | --- | --- |
| 低资源占用 | C++20、Win32/GDI，无浏览器运行时；无常驻刷新计时器 | 本机 10 便签/1000 任务：35.54 MiB 工作集、2.58 MiB 私有内存，10 秒 CPU 时间增量 0；已测 |
| 可设置开机启动 | 管理窗口复选框，当前用户 Run 项，路径加引号，带 --startup | 原生注册表适配器无头测试及隔离注册表集成测试通过；未修改用户真实启动设置 |

| 模式二：置顶 | 独立顶层窗口，WS_EX_TOPMOST | 激活普通遮挡窗口后，便签仍在上层；截图及 WindowFromPoint 实测通过 |
| 模式三：独立普通窗口 | 普通窗口边框、任务栏窗口属性、非置顶 | 原生适配器、进程集成及实际界面操作通过 |
| 桌面锁定时鼠标不触发正文操作 | 分层窗口输入穿透；领域命中测试拒绝锁定正文 | 无头命中测试与真实进程样式测试通过；产品实际桌面鼠标穿透待补 |
| 解锁/锁定及按钮位置设置 | 独立解锁窗口，四角与边距；正文标题栏可再次锁定 | 四角/DPI 无头测试、按钮原生窗口与重建测试通过；实际桌面点击待补 |
| 多便签、各自标题和颜色 | 独立 Note 模型、窗口、菜单和持久化 | 无头及程序集成测试通过 |

| 任务图标和颜色 | 预设/自定义 Unicode 图标、颜色选择器 | 完整字段存储和程序集成通过；中文/emoji 输入实测通过 |

## 完成判定

目标仍未宣告完成：显示桌面后的可见性及桌面锁定鼠标交互证据还需补齐。
已向用户请求一次手动 Win+D 检查；Computer Use 技能禁止自动发送 Windows 键快捷键。

Explorer 进程重启、多屏不同 DPI 属于额外稳定性检查，目前仅测试了窗口重建、
替换宿主重新挂接、DPI 策略及负坐标工作区计算，不宣称已完成所有实机环境测试。

证据入口：`app-integration-results.json`、`app-performance-results.json`、
`product-ui-validation.md`、`product-window-layer-results.json`；测试代码位于 `tests/native/` 和
`scripts/test-app-integration.py`。
