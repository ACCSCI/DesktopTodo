# 固定锁定控件与视觉更新

- 桌面模式始终保留同一个独立按钮窗口，默认右上角；点击切换锁定 / 解锁，
  按钮窗口句柄、矩形和层级保持不变。旧的位置配置仍可用，两种状态共同使用。
- 使用闭锁 / 开锁线条图标呈现当前状态，紫色表示已锁定。
- 更多菜单入口移到锁形按钮左侧，正文不再出现第二个不同位置的“锁”按钮。
- 浅色便签、圆角任务卡、低对比阴影、统一筛选入口及紫色添加按钮。
- 锁梁改为显式贝塞尔曲线：闭锁轮廓连接完整，开锁有明确缺口，两者锁体相同。
- 标题栏两按钮采用相同尺寸和垂直中线；筛选标签/箭头、输入框/添加按钮由
  共享布局矩形定位。标题和任务的编辑框使用相同字体与文字起点，编辑时不跳位。
- 拖动把手、完成标记、菜单、下拉箭头和空状态使用同一套原生矢量绘制。
- 应用和托盘使用新的多尺寸待办图标，可用 `python scripts/create-app-icon.py`
  从项目代码重新生成，无额外运行时依赖。

## 验证

- 无头策略测试覆盖多种 DPI 下两种锁定状态的位置一致，以及菜单和锁按钮命中区。
- 原生 GDI 测试检查各尺寸矢量图标确实绘制、像素未越界；检查 ICO 资源可加载。
- 程序集成测试调用实际按钮的事件处理，验证解锁、再次锁定及同一窗口/坐标。
- Computer Use 实际检查普通窗口中的新版任务卡、筛选入口和输入区域。
- 完整质量检查仍执行 `npm run check`、`npm run test:native` 与 Lefthook。
