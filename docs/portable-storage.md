# 便携存储与数据库管理

## 文件位置

- 默认数据库：与 `DesktopTodo.exe` 同目录的 `todo.sqlite`。
- 备份：当前数据库目录中的 `backups/`。
- 存储配置：程序目录内的 `DesktopTodo.ini`。子目录用相对路径，外部目录用绝对路径。
- `--data-dir` 仍可显式覆盖默认配置，供隔离测试及高级用法使用。

旧版 AppData 数据只在新位置没有数据库时导入；使用 SQLite 在线备份 API 包含 WAL
中的已提交数据，并验证新库。旧版来源保留为安全副本，确认迁移成功后可自行删除。

## 设置与安全性

管理窗口点击「存储设置」可选择新目录。迁移先复制数据库与已有备份，校验所有模型
字段，再原子保存配置、切换当前存储。目标已有库、目标正被使用、配置写入失败都会
拒绝切换，原数据仍可用。成功后移除原活动数据库；若文件被其他程序占用，会给出
提示。原有备份不会自动删除。

不能将新存储位置放进旧备份目录，避免递归复制。迁移的复制不跟随符号链接。

## 清理与备份

- 整理数据库：检查点与 VACUUM，回收空闲空间，保留便签内容。
- 清空全部数据：连续三次确认，任一次取消均不修改数据。
- 清空不新建任何备份；旧备份保留。活动数据库内容清空并回收空间，撤销历史清除。
- 手动备份、显式恢复独立使用。自动备份在每日第一次启动时生成，保留最近 7 份。
- 删除单个便签仍使用原有可撤销操作，与清空整个数据库区别明确。

## 卸载

这是便携版。退出后删除程序文件夹即可移除其中的程序、默认数据库及备份。
如设置了外部存储，该外部目录需要单独处理，不会自动删除。开机启动应先取消。
旧版本保留的 AppData 安全副本也不会被删除程序文件夹这一操作自动移除。

## 验证

无头测试覆盖位置规则、WAL 迁移、Unicode 配置、源数据保留、已有目标保护、失败回滚、
递归路径拒绝、整理不改内容、三阶段确认。程序专项覆盖实时迁移、配置写失败、
三次取消、清空不新增备份、恢复、默认程序目录及重启读取新位置。

输入框已加入可见焦点边框、桌面显式合成光标，刷新随焦点和输入事件发生；默认任务
圆点按任务行中心绘制。实际鼠标点击、中文输入与 Enter 保存检查通过。
